# Математический калькулятор

Сайт из одного файла `index.html`: геометрия и алгебра, калькулятор и тренажёр с подсказками. Ничего устанавливать не нужно, все вычисления выполняются в браузере.

**Геометрия.** 14 фигур (треугольник, круг, трапеция, многоугольник по координатам, шар, цилиндр, конус, параллелепипед, пирамида и другие). Точки на схеме можно перетаскивать, значения в полях меняются вместе с ними.

**Алгебра.** Значение выражения, многочлены (разложение на множители, корни, производная, первообразная), НОД и НОК, линейное и квадратное уравнения, система двух уравнений, уравнение с x, арифметическая и геометрическая прогрессии. Графики; в линейном и квадратном уравнениях точки на графике тоже можно тянуть.

**Тренажёр.** Задачи с новыми числами на трёх уровнях сложности, две подсказки к каждой задаче, итог с разбором ошибок.

Прямые ссылки: `…/#algebra` — алгебра, `…/#trainer` — тренажёр по геометрии, `…/#algebra-trainer` — тренажёр по алгебре.

## Как открыть на своём компьютере

Скачайте `index.html` и откройте его двойным щелчком в любом современном браузере.

## Как выложить сайт на GitHub Pages

Через сайт GitHub, без командной строки:

1. Войдите на [github.com](https://github.com) и нажмите **New repository** (зелёная кнопка или «+» вверху справа).
2. Введите имя, например `math-calculator`, выберите **Public** и нажмите **Create repository**.
3. На странице нового репозитория нажмите **uploading an existing file**, перетащите в окно `index.html` и `README.md` и нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
5. Через минуту-две сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/math-calculator/` (адрес показывается вверху той же страницы Settings → Pages).

То же из командной строки:

```bash
git init
git add index.html README.md
git commit -m "Математический калькулятор"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/math-calculator.git
git push -u origin main
```

После этого включите Pages (пункт 4).

## Примечания

- GitHub Pages бесплатен для публичных репозиториев.
- Шрифты IBM Plex подгружаются с Google Fonts. Без интернета подставляются системные шрифты, остальное работает так же.
- Чтобы изменить сайт, правьте `index.html` и загрузите новую версию в репозиторий; Pages обновится сам.
